# 걸어 다니는 교회 — 중고등부 셀프 스터디 웹앱

마가복음 11:15–19, 고린도전서 3:16을 바탕으로 한 설교 내용을,
학생들이 스마트폰으로 접속해 시나리오 선택과 셀프 스터디로 체험하는 웹앱입니다.

## 구성

- 학생용 페이지 (`/`) : 이름 입력 → 시나리오 4개(선택형) → 셀프 스터디 ①(체크+서술) →
  셀프 스터디 ②(서술) → 제출
- 선생님용 페이지 (`/admin.html`) : 비밀번호 로그인 → 전체 제출 목록 → 학생별 상세 응답 조회 / 삭제
- 제출 데이터는 서버의 `data/submissions.json` 파일에 자동 저장됩니다.

## 1. 처음 한 번만: 실행 환경 준비

1) 컴퓨터에 **Node.js**가 필요합니다. 없다면 https://nodejs.org 에서 "LTS" 버전을 내려받아 설치하세요. (설치 후 껐다 켜기)
2) 터미널(맥: 터미널 앱 / 윈도우: 명령 프롬프트 또는 PowerShell)을 엽니다.
3) 이 폴더(`walking-temple-app`)로 이동합니다. 예:
   ```
   cd 바탕화면/walking-temple-app
   ```
4) 필요한 패키지를 설치합니다.
   ```
   npm install
   ```

## 2. 서버 실행하기

```
npm start
```

아래와 같은 메시지가 뜨면 정상적으로 실행된 것입니다.

```
✝ 걸어 다니는 교회 서버가 실행되었습니다!
   학생용 페이지:   http://localhost:3000
   선생님용 페이지: http://localhost:3000/admin.html
```

- 이 터미널 창을 닫으면 서버도 꺼집니다. 모임이 끝날 때까지 켜 두세요.
- 종료하려면 터미널에서 `Ctrl + C`를 누르세요.

## 3. 학생들이 접속하는 방법 (같은 와이파이망 사용 시)

같은 컴퓨터에서만 여는 것이 아니라, 아이들이 **각자 스마트폰**으로 접속하게 하려면
컴퓨터와 스마트폰이 **같은 와이파이(Wi-Fi)** 에 연결되어 있어야 합니다.

1) 서버를 실행한 컴퓨터의 **내부 IP 주소**를 확인합니다.
   - 맥: 터미널에서 `ipconfig getifaddr en0` 입력
   - 윈도우: 명령 프롬프트에서 `ipconfig` 입력 후 "IPv4 주소" 확인 (예: `192.168.0.15`)
2) 학생들에게 아래 주소를 알려주고 스마트폰 브라우저에서 접속하게 합니다.
   ```
   http://[컴퓨터의 IP 주소]:3000
   ```
   예) `http://192.168.0.15:3000`
3) QR코드를 만들어 화면에 띄워주면 접속이 훨씬 편해요. (예: 네이버 "QR코드 만들기" 등 무료 도구 사용)

> 💡 인터넷이 되는 곳이라면 어디서나 접속 가능하게 하려면, Render, Railway, Cafe24 등
> 무료/저가 Node.js 호스팅 서비스에 이 폴더를 그대로 배포하면 됩니다. (선택 사항)

## 4. 선생님이 결과를 확인하는 방법

1) 같은 와이파이의 다른 기기(혹은 서버를 실행한 컴퓨터)에서 아래 주소로 접속합니다.
   ```
   http://localhost:3000/admin.html
   ```
   (다른 기기에서 접속할 땐 `localhost` 대신 위에서 확인한 IP 주소를 사용하세요.)
2) 관리자 비밀번호를 입력합니다. **기본 비밀번호는 `temple2026`** 입니다.
3) 제출한 학생 목록이 표에 뜹니다. **[보기]** 버튼을 누르면 그 학생의
   시나리오 선택과 셀프 스터디 ①·② 답변을 한눈에 볼 수 있어요.
4) 더 이상 필요 없는 응답은 **[삭제]** 버튼으로 지울 수 있습니다.

### 관리자 비밀번호 바꾸는 방법 (권장)

`server.js` 파일을 열어 아래 줄을 찾아 원하는 비밀번호로 바꾸고 저장한 뒤,
서버를 껐다 다시 켜세요 (`Ctrl+C` 후 `npm start`).

```js
const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || "temple2026";
```

## 5. 내용(설교/시나리오) 수정하고 싶을 때

모든 시나리오 문구와 셀프 스터디 문항은 `public/app.js` 파일 맨 위쪽
`SCENES`와 `CLEAN_UP_OPTIONS` 부분에 있습니다. 텍스트만 원하는 대로 바꾸면
디자인이나 기능은 그대로 유지된 채 내용만 바뀝니다. 저장 후 브라우저를
새로고침(F5)하면 바로 반영됩니다.

## 6. 파일 구조

```
walking-temple-app/
├── package.json        # 패키지 설정
├── server.js            # 서버 (제출 저장 / 관리자 조회 API)
├── data/
│   └── submissions.json # 학생 제출 데이터 저장 파일 (자동 생성/갱신)
└── public/
    ├── index.html        # 학생용 페이지
    ├── admin.html         # 선생님용 페이지
    ├── style.css           # 전체 디자인
    ├── app.js               # 학생용 로직 (시나리오 내용 포함)
    └── admin.js              # 선생님용 로직
```

## 7. 자주 묻는 질문

**Q. "npm: command not found"라고 떠요.**
A. Node.js가 설치되지 않았거나, 설치 후 터미널을 재시작하지 않은 경우입니다.
Node.js를 설치하고 터미널을 완전히 껐다가 다시 열어보세요.

**Q. 학생 수가 많은데 데이터가 안전할까요?**
A. `data/submissions.json` 파일에 계속 누적 저장됩니다. 모임이 끝난 뒤
이 파일을 복사해 백업해두시길 권해요.

**Q. 다음 주에도 같은 데이터가 남아있으면 곤란해요.**
A. 관리자 페이지에서 학생별로 삭제하거나, `data/submissions.json` 파일 내용을
`[]` 로 바꿔 저장하면 전체 초기화됩니다.
